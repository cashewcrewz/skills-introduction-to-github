# Github profile 

#### What is a .md file?
> A .**md** file is a plain text document written in **Markdown**.
>> It as a lightweight markup language that uses symbols to format the texts.
>> Markdown was created in 2004 by John Gruber and Aaron Swartz. They wanted something simpler than HTML. but also portable, and free.

___

### Basic Formatting Syntax
- **Headings**
  - An `#` or hashtag symbol is used
  - Heading 1 or H1 is equivalent to `#`
    - Can be up to Heading 6 or H6 equivalent to `######`

- **Bold and *Italic***
  - `**bold**` for **bold**
  - `*italic*` for *italic*
 
- **Unordered lists:** 
  - symbol `-` for this line
    * symbol `*` for this line
      + symbol `+` for this line

- **Ordered lists:**
1. Just precede each line with a number 
2. like this `1.`
3. then next line `2.`

- **Nested lists:**
  - `tab` is used to indent.

1. This is
2. without
3. indention

   1. this is
   2. with
   3. 1 indention

      1. this is
      2. with
      3. 2 indentions

- **Horizontal Rule**
  - Three dashes, underscores, asterisk
  - like `---`,`___`,`***`

- **Code**
  - single backtick **(`)** for inline code.
  - triple backticks **(```)** for block code
 
- **Block Quotes**
  - `>` symbol is used to make quotes
  
  > `>` Like
  >> `>>` This


- More [GFM Syntax Here.](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)

#### Github Flavored Markdown (GFM)
Github has supported markdown files and GFM was built on top of CommonMark. It added support for tables, task checklists, strikethrough text and even syntax highlighting.
